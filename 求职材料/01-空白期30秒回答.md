# 空白期（2022 → 2026）30 秒回答话术

> 用途：面试被问到「2022 年毕业到现在这几年你在做什么」时使用。
> 原则：**不撒谎、不诉苦、不道歉**。把「在家闲着」翻译成「主动选择的过渡期 + 转型准备」。

---

## ⚠️ 使用前必读（重要）

这份话术是**框架**，不是标准答案。里面的「做了什么」必须换成**你真实做过的事**。

面试官追问细节时，编造的内容 100% 会露馅。所以：
- 先看下面【第三步】，把你的真实经历填进去
- 只保留你能展开讲 2 分钟的部分

---

## 一、核心叙事结构（4 句话）

```
① 承认事实（1 句，不回避、不解释）
② 说明这段时间在做什么（1-2 句，必须是真实内容）
③ 收束到"我为什么回到游戏行业"（1 句，给出确定的结论）
④ 落到"我现在在做什么"（1 句，展示行动力）
```

**关键**：不要花时间解释「为什么没转正就走了」，那是一次性说清的事，不要反复强调。

---

## 二、三个版本（按你的真实情况选一个）

### 版本 A：如果实习后又试过其他方向

> 「2022 年毕业后我在这家游戏公司实习了大半年，主要做的是 [具体工作，如 UE 客户端 / 系统开发]。实习结束后因为 [一句话，如：公司编制调整 / 我发现自己更想打牢底层基础]，我没有留下来。
>
> 之后这两年多我在 [某件事，如：一边接一些远程的开发零活 / 一边系统补计算机基础]，同时也在想清楚自己到底要做什么。
>
> 最后我确认了自己还是想做游戏，尤其是 UE 的技术方向。
>
> 所以从今年年初开始，我系统地做 UE 的 GAS 项目，目前已经完成 [进度]，并且在持续扩展自己的玩法系统。」

### 版本 B：如果这段时间主要是自学 + 刷题

> 「毕业实习结束之后，我没有马上找下一份工作，而是花了几年时间做两件事：一是系统补计算机基础和自己感兴趣的技术方向，二是想清楚职业方向。
>
> 期间我写过 [博客 / 项目 / 开源的小东西，要真实]，也刷过一段时间的算法题。
>
> 但兜了一圈之后，我确认自己真正想做的是游戏开发。
>
> 所以今年年初我开始系统地做 UE 项目，重点在 GameplayAbilitySystem 和网络同步这块，现在已经能独立排查联机环境下的复制问题了。」

### 版本 C：如果确实没做什么（最诚实的版本）

> 「说实话，毕业后实习那大半年之后，我有几年时间状态不是很好，没有持续地做一份工作，主要是在家里做了一些零散的事情，也在考虑要不要继续做游戏。
>
> 直到今年年初我才想清楚，也才真正沉下来做项目。
>
> 从年初到现在，我完成了 [项目情况]，也在这段时间里确认了：我是真的想做游戏，而且我能坐下来把复杂的系统啃下来。
>
> 我知道这几年是空白，这个我不解释。但我想说的是，从今年开始我的节奏是稳定的。」

> 💡 **版本 C 反而可能加分**：诚实 + 有反思 + 有近期行动，比编一个漏洞百出的故事强。
> 很多面试官对"想清楚了才回来"的人是接受的，对"遮遮掩掩"的人是不接受的。

## 三、把你的真实经历填进来（必做）

回答下面 4 个问题，答案就是你的话术：

1. **2022 实习结束后到 2026 年初，你具体做过什么？**（哪怕很小的事）
   - 接过的活？学的技术？做的项目？写的笔记？刷的题？
   - ________________________________________________________________

2. **为什么离开上一家实习公司？**（一句话，不抱怨、不甩锅）
   - ________________________________________________________________

3. **是什么让你决定回来做游戏 / 做 UE？**（要有一个具体的触发点）
   - ________________________________________________________________

4. **从 2026 年初到现在，你做了什么？**（用数字，比如"做了 X 个月的 UE 项目，完成了 Y"）
   - ________________________________________________________________

把这 4 个答案按【一、核心叙事结构】串起来，就是你的 30 秒回答。

## 四、可能被追问的问题 + 应对

| 追问 | 应对原则 |
|---|---|
| 「实习为什么没转正？」 | 一句话带过，**不抱怨公司**。可以说「当时公司 HC 调整 / 我自己也还没想清楚」。说完立刻转回"现在" |
| 「这几年技术是不是生疏了？」 | 承认，但给出反证：「生疏的部分我用这几个月补回来了，比如我现在能独立排查 GAS 的复制问题，这个你可以看我的项目」 |
| 「你 985 毕业，为什么做游戏？」 | 别把 985 当包袱。说「因为想做这个」，然后讲你为它做了什么 |
| 「为什么这么久才找工作？」 | **不要道歉超过一次**。温和地说「我确实绕了弯路，但从今年开始我在稳定推进」，然后展示你的 commit 记录 |
| 「你有什么作品？」 | **这是你的主场**。直接讲项目 + 遇到的难点（用《技术难点记录》里的内容） |

## 五、绝对不能说的话

| ❌ 不要说 | ✅ 换成 |
|---|---|
| 「在家待着」「闲着」 | 「在做 XX / 在想清楚方向」 |
| 「一直没找到合适的工作」 | 「在调整方向，也在补基础」 |
| 「那公司太坑了，不给我转正」 | 「当时的情况不太合适继续」 |
| 「我玩游戏玩了一段时间」 | 如果非得说，强调「也是在研究游戏本身」 |
| 「我也不知道怎么就过了这么久」 | 「这几年确实是我的低谷，但我现在想清楚了」 |

## 六、语气和态度（比内容更重要）

- **不要内疚**。面试官不关心你的过去，关心你能不能干活。
- **不要解释太多**。空白期讲 20 秒就够了，剩下的时间留给"我做了什么"。
- **要有终点感**。让面试官觉得「这人已经想清楚了，从今年开始是稳定的」。
- **微笑 + 平稳的语气**。紧张地解释会被读成心虚；平静地承认会被读成成熟。

## 七、一段可直接背诵的完整版（版本 A 改写）

> 「好，我简单说一下。2022 年毕业之后，我在这家游戏公司实习了大半年，做的是 UE 客户端的部分开发。实习结束之后我没有留在那里，主要还是自己想的方向和公司当时的需求不太一致。
>
> 之后这两年多，我一边做了一些零散的技术事情，一边也在想清楚自己要做什么。中间也确实走了弯路，这一点我不回避。
>
> 想清楚之后我的结论是：我还是想做游戏，而且是做 UE 的技术方向。
>
> 所以从今年年初开始，我系统地做 UE 的 GAS 项目，从角色、技能、属性到联机同步全部自己实现了一遍，目前在做玩法扩展。这段时间我的节奏是稳定的，每天都有推进，项目也有连续的提交记录。」

（约 30-35 秒，语速正常）

## 八、简历里怎么写（配套）

**不要把空白期写成"gap"或者留空**。用一段"自主学习/项目经历"盖住：

```
2026.01 - 至今     UE5 游戏开发（自主学习 + 项目实践）
                   · 基于 GameplayAbilitySystem 实现角色、技能、属性、Debuff 系统
                   · 独立完成 Listen Server 联机测试与网络复制问题排查
                   · 详见项目：github.com/AiBiaoJD/GameAura
```

**HR 看简历时不会深挖时间线，他们看的是"最近在做什么"。**
你把最近的事写得具体、有技术含量，空白期的影响就会被大幅削弱。
